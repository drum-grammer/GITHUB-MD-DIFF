렌더링 diff 엔진 — 원문에서 GitHub 표기 HTML까지

잎 블록은 확장과 같은 기본 파서(sourceBlocks)로, 렌더링은 플러그인을 켠 markdown-it 15로 따로 얻고 원문 줄 범위로 잇는다. 원문 HTML은 DOMPurify + jsdom으로 정화한다. 옛·새 잎은 확장이 GitHub 화면에서 쓰던 alignBlocks를 더 큰 한도로 짝짓고, 원문이 아니라 렌더링으로 바뀜을 판정한다. 렌더링에 안 보이는 변경에는 "원문만 바뀜" 막대를 단다. 결과 HTML은 GitHub rich diff와 같은 표기라 확장의 접기·표 합치기·이동이 그대로 돈다.
