Markdown Diff Cat works again on GitHub's signed-in "Files changed" page. On 2026-10-14 GitHub renamed the class names on that page, and 1.5.0 stopped rendering, folding and commenting there without a warning. 1.5.1 finds files in a way that survives that kind of change, and tells you when it cannot read the page.

**Install or update:** [Chrome Web Store](https://chromewebstore.google.com/detail/markdown-diff-cat-for-git/kabekbbeoajhpbcppidepmcbbjjochlj)

## Fixed

- **Works on the signed-in "Files changed" page again.** GitHub changed its CSS class names from `Diff-module__diff__hash` to `diff__hash`, and 1.5.0 found no files. 1.5.1 finds each file by its link address (`#diff-…`, the address GitHub's own file links use) and the page layout first, and accepts both class name formats, so it keeps working if GitHub switches back. The signed-out page was not affected. What happened and why it was missed: [1.5.1 report](../reports/v1.5.1-github-class-names.md)

## New

- **A warning instead of silence.** When the extension sees files on the page but cannot read any of them for a few seconds, it shows its warning: the **!** on the toolbar icon and a note in the corner with a prefilled **Report on GitHub** link

## Permissions and privacy

Same permissions as 1.0.0: `storage` for the on/off setting, and it runs only on `https://github.com/*`. When you are signed in, the extension talks to GitHub, and only to GitHub, with the session you already have.

## How it was tested

- Before the fix, 1.5.0 against GitHub on 2026-10-14: 6 signed-in end-to-end tests failed and the read-only canary broke on 3 of 7 checks, all with "file not found", while the pull request data checks and the signed-out page passed
- Unit and DOM tests: 351, where the file tests run on three versions of the page — the old class names, the new ones, and none at all
- `pnpm verify release` on `7ca3da6` (the same extension code as this package): end-to-end tests with writes 13, canary 9/9 including the new "class name format" check, release scenarios on a public test repository ([drum-grammer/markdown-diff-cat-testbed](https://github.com/drum-grammer/markdown-diff-cat-testbed)) 60/60 in 5 GitHub diff layouts, re-exploration of 16 public pull requests with no warnings or extension errors and 99.8% of rendered blocks matched to their source lines, extension CPU 89 ms and 255 ms on the two performance pull requests
- A new end-to-end test removes the file ids and class names from a live page and checks that the warning appears
- `pnpm release check` on `0873956` ran without its end-to-end step: the new warning test raced GitHub drawing the lower files of a 20-file pull request (the extension read those files correctly, so no warning was due). The test now uses a one-file pull request and passed 3 times alone and with the other end-to-end tests on the same extension code

## 한국어

GitHub 로그인 화면의 "Files changed"에서 다시 동작해요. 2026-10-14 GitHub가 그 화면의 클래스 이름을 바꿔서, 1.5.0은 경고 없이 렌더링·접기·코멘트를 멈췄어요.

- **고친 것**: 파일을 링크 주소(`#diff-…`)와 화면 구조로 먼저 찾고, 클래스 이름은 옛 형식과 새 형식을 둘 다 받아요. GitHub가 되돌려도 그대로 돌아요. 로그아웃 화면은 영향이 없었어요
- **새로 생긴 것**: 화면에 파일이 보이는데 몇 초 넘게 하나도 못 읽으면, 툴바 **!**와 구석 안내("Report on GitHub" 링크)로 알려요
- **권한은 1.0.0과 같아요**
