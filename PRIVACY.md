# Privacy Policy — Markdown Diff Cat for GitHub

Effective date: 2026-10-08

Markdown Diff Cat for GitHub ("the extension") does not collect, store, sell, or share any personal data.

## What the extension does with data

- **Page content.** On `https://github.com/*` pages, the extension reads the pull request "Files changed" page that is already open in your browser so it can switch Markdown files to the rendered view, fold unchanged sections, and merge changed tables. This happens only inside your browser. Nothing from the page is sent anywhere.
- **Comments, when you are signed in to GitHub.** To let you comment in the rendered view, the extension sends requests to `github.com` only, with the GitHub session you already have. It loads the pull request's review threads and commit IDs, loads the Markdown files shown on the page (GitHub may serve the file from its own file host, `raw.githubusercontent.com`), and posts, replies to, or resolves review comments only when you click to do so. These requests go directly from your browser to GitHub, as GitHub's own page does. The developer receives nothing, and no token is stored or used.
- **Problem reports.** When the extension cannot read the page or commenting stops working, a note offers a "Report on GitHub" link. It only opens GitHub's new-issue form with the problem, extension version, page type, browser name and major version, and date filled in — no repository name, pull request URL, or comment text. Nothing is sent unless you submit the form yourself.
- **One setting.** The extension saves whether it is turned on or off in `chrome.storage.local` on your device. This setting never leaves your device.

## What the extension does not do

- No analytics, tracking, cookies, or advertising.
- No requests to anyone other than GitHub, and no remote code.
- No access to websites other than `github.com`.
- No account, sign-in, or contact information is collected.

## Contact

Questions or concerns: open an issue at https://github.com/drum-grammer/GITHUB-MD-DIFF/issues

## 개인정보처리방침 (한국어)

시행일: 2026-10-08

Markdown Diff Cat for GitHub(이하 "확장")은 개인정보를 수집·저장·판매·공유하지 않습니다.

- **페이지 내용:** `https://github.com/*`에서 이미 열려 있는 PR "Files changed" 화면을 브라우저 안에서만 읽어, 마크다운 파일을 렌더링 보기로 바꾸고 바뀌지 않은 구간을 접고 바뀐 표를 합칩니다. 페이지 내용은 어디로도 보내지 않습니다.
- **코멘트(GitHub에 로그인한 경우):** 렌더링 보기에서 코멘트를 달 수 있도록, 이미 로그인된 GitHub 세션으로 `github.com`에만 요청합니다. PR의 리뷰 스레드와 커밋 ID, 화면에 나온 마크다운 파일을 읽고(GitHub가 자체 파일 호스트 `raw.githubusercontent.com`에서 내줄 수 있습니다), 사람이 누를 때만 리뷰 코멘트를 올리거나 답하거나 해결합니다. 요청은 GitHub 화면이 하는 것처럼 브라우저에서 GitHub로 바로 갑니다. 개발자는 아무것도 받지 않고, 토큰을 저장하거나 쓰지 않습니다.
- **문제 보고:** 화면을 읽지 못하거나 코멘트 기능이 멈추면 안내에 "GitHub에 알리기" 링크가 나옵니다. 링크는 GitHub 새 이슈 작성 화면을 열 뿐이며, 문제·확장 버전·화면 종류·브라우저 이름과 주 버전·날짜만 채워 둡니다(저장소 이름·PR 주소·코멘트 글은 넣지 않습니다). 직접 제출하기 전에는 아무것도 보내지 않습니다.
- **설정 하나:** 켜짐·꺼짐 상태만 기기의 `chrome.storage.local`에 저장하며, 기기 밖으로 나가지 않습니다.
- 분석·추적·쿠키·광고, GitHub 이외로의 요청, 원격 코드, github.com 이외 사이트 접근이 없습니다.
