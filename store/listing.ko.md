# 스토어 등록 정보 — 한국어

**이름** (`_locales/ko/messages.json`): Markdown Diff Cat for GitHub

**요약** (매니페스트 설명, 132자 이하): GitHub PR의 마크다운 변경을 렌더링된 모양으로, 바뀐 부분만 보여 주고 그 자리에서 코멘트를 달아요.

**카테고리:** 개발자 도구 · **언어:** 한국어

## 상세 설명

AI가 설계 문서를 길게 써 주면서, PR에서 마크다운 문서를 리뷰하기가 더 힘들어졌어요.

• 렌더링 보기는 파일 전체를 펼쳐서, 바뀐 곳을 찾으려면 수백 줄을 스크롤해야 해요.
• 원문 보기는 바뀐 부분만 보여 주지만 마크다운 기호·표·코드 블록에 묻혀 읽기 어려워요.
• 리뷰 코멘트를 달려면 다시 원문 보기로 돌아가야 해요.

Markdown Diff Cat은 렌더링된 문서에서 바뀐 부분만 보여 주고, 그 자리에서 코멘트까지 달게 해 줘요.

이런 걸 해요
• 마크다운 파일(.md, .markdown, .mdx)은 열자마자 렌더링 보기로 바꿔요.
• 바뀌지 않은 구간은 한 줄 막대로 접어요. 막대마다 숨긴 블록 수와 마지막 제목이 보이고, 누르면 그 자리만 펼쳐져요. 파일 전체를 한 번에 펼칠 수도 있어요.
• 표: 행 하나만 바뀌어도 GitHub는 옛 표 전체와 새 표 전체를 보여 줘요. Markdown Diff Cat은 바뀐·추가된·삭제된 행만 남긴 표 하나로 합치고, 바뀐 칸은 이전 → 이후로 보여 줘요. 언제든 원래 표로 바꿀 수 있어요.
• 렌더링 보기에서 바로 코멘트(GitHub에 로그인한 경우): 블록에 마우스를 올리고 +를 누르거나, 다른 블록까지 끌면 그 범위에 달아요. 코멘트는 맞는 원문 줄에 붙는 보통의 GitHub 리뷰 코멘트예요. 단일 코멘트로 달거나 리뷰에 넣을 수 있어요. 이미 달린 리뷰 스레드는 그 블록 아래에 보이고, 답글과 해결도 그 자리에서 해요. 파일 전체에 단 코멘트는 파일 맨 위에 보여요.
• 코멘트 상자는 GitHub 상자와 똑같이 동작해요: 쓰기·미리보기 탭, 같은 서식 도구 막대와 단축키, 그리고 원래 줄을 제안(suggestion) 블록에 넣어 주는 제안 버튼. 작성자는 제안을 한 번에 반영해요. 답글 상자에도 있어요.
• 내가 쓴 코멘트는 그 자리에서 고치거나 지우고, GitHub에 보일 모양으로 미리 볼 수 있어요.
• 바뀐 곳 사이 이동: 파일 맨 위에 바뀐 곳과 열린 리뷰 스레드 수가 보여요. ]와 [로 다음·이전 바뀐 곳, }와 {로 스레드 사이를 옮겨요.
• 방해하지 않아요: <>를 눌러 원문 보기로 바꾼 파일은 되돌리지 않아요. 접어 둔 파일·Viewed 표시한 파일도 그대로 둬요.
• 컬러 아이콘은 켜짐, 회색 아이콘은 꺼짐이에요. 툴바 아이콘을 누르면 바뀌어요.
• 확장 화면의 문구는 GitHub 화면에 맞춰 영어로 나와요.

새 "Files changed" 화면과 옛 화면 모두에서 동작해요.

개인정보
수집하는 데이터와 원격 코드가 없어요. github.com에서만 동작해요. 로그인한 경우에는 이미 있는 세션으로 GitHub하고만 통신해요 — 리뷰 스레드와 화면의 마크다운 파일을 읽고, 내가 쓴 코멘트를 올려요. 개발자나 다른 곳으로는 아무것도 보내지 않고 토큰도 쓰지 않아요. 켜짐·꺼짐 설정은 기기 안에만 저장돼요.
